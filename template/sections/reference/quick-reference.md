## Quick Reference

### Verification Commands

| Language | Lint | Build | Test |
|----------|------|-------|------|
| Go | `make go-lint` | `make check-build` | `make go-test` |
| TypeScript | `npm run lint` | `npm run build` | `npm test` |
| Shell | `make shfmt` | - | - |

### Git Operations

```bash
# Allowed
git add, git commit, git push

# NOT Allowed
git merge, gh pr merge, push to main
```
